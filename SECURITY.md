# Politique de Sécurité

## Signaler une vulnérabilité
Si vous trouvez un secret exposé (token, mot de passe, ID sensible) ou une faille de logique pouvant mener à la fuite de données personnelles de candidats :
**NE CRÉEZ PAS D'ISSUE PUBLIQUE.**

Veuillez contacter directement l'administrateur du projet en privé ou utiliser le système d'advisory privé de GitHub si activé.

## Données Personnelles
Ce workflow traite des CV (noms, adresses, expériences). Ne jamais uploader d'exemples de données réelles dans ce dépôt. Utilisez toujours des données factices (ex: John Doe).
